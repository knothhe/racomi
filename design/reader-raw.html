# H2 设计先行

把用户看见和操作的界面先做成可审阅的设计，再让实现与设计一致。

## 确定这次交付

- **设计或修改设计**：完成布局、文案、可见状态与交互说明。
- **设计并实现**：先完成设计文件，再修改实现并对照验证。

> 用户仅需局部改动时，不要求额外的汇报文档或全量截图。

## 预览与验证

从仓库根目录启动本地预览：

```sh
python3 -m http.server 4780 --bind 127.0.0.1 --directory design
```

| 状态 | 可以做什么 |
| --- | --- |
| 正常 | 阅读文档、切换原文 |
| 失败 | 重试读取 |

继续阅读 [设计判断与实现对照](references/workflow.md)。
