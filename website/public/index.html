需要的功能，恰好够用

从发现到部署，所有操作都在本机完成，不需要账号。

发现与导入

浏览 skills.sh 榜单或搜索，从 Git 仓库、本地目录导入；可挑选安装或订阅整个仓库，手动同步更新，上游移除或改名时自动标记。

预设组织

把常用技能组合成预设，多个项目复用。来源、预设与单个技能按并集合并去重，同一技能只保留一份。

项目与全局部署

应用到项目或 Agent 全局目录，支持多目录、复制与软链接部署。应用前预览新增、更新、移除与冲突，不会误删你的文件。

快照与备份

本地快照随时回滚，ZIP 备份导入导出，也可以直接导入 skills-manager 的数据。

加密云同步

可选 S3 / Cloudflare R2 端到端加密同步与云端历史恢复；R2 支持 OAuth 一键配置，无需 racomi 账号。

原生且轻量

Go + 系统 WebView 构建，托盘常驻、开机自启、签名应用内更新。明暗主题、Omarchy 配色，简体中文／繁體中文／English。

三步完成部署

刷新来源、同步技能、应用目录相互独立，每一步都由你决定。

导入

从 skills.sh、Git 或本地目录添加技能来源。

组织

为项目和全局选择技能、预设或整个来源，选择自动保存。

应用

预览变化后一次应用到多个项目与 Agent 目录。

安装

导入和刷新 Git 来源需要本机安装 Git。所有安装包见 GitHub Releases。

推荐使用 Homebrew 安装，之后的升级由应用内更新完成：

brew install --cask knothhe/tap/racomi
要求macOS 13+ (Apple Silicon)
安装包racomi-*-aarch64-macos.zip

应用仅有 ad-hoc 签名、未经公证。若被拦截，可到“系统设置 → 隐私与安全性”选择“仍要打开”，或执行 xattr -dr com.apple.quarantine /Applications/racomi.app。

下载 ZIP 包，解压到当前用户可写的目录后运行 racomi.exe。

要求Windows 10/11 x64 · WebView2 Runtime
安装包racomi-*-x86_64-windows.zip

EXE 尚未做 Authenticode 签名。软链接部署需要开启开发者模式，否则使用默认的复制部署。

一条命令完成安装，适用于 Arch、Debian／Ubuntu、Fedora、openSUSE 及其衍生发行版：

curl -fsSL https://github.com/knothhe/racomi/releases/latest/download/install.sh | sh
要求x86_64 · WebKit2GTK 4.1
安装包racomi-*-x86_64-linux.tar.gz

脚本会补装缺少的 WebKit2GTK 4.1 与 Git，校验 SHA-256 后安装到 ~/.local/bin/racomi。参数写在 sh -s -- 后：--version X.Y.Z、--skip-deps、--uninstall。
