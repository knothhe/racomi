racomi for Windows x64

Requirements: Windows 10/11 x64, Microsoft Edge WebView2 Runtime, and Git for
Git sources. WebView2: https://developer.microsoft.com/microsoft-edge/webview2/

Install:
  Get-FileHash .\racomi-*-x86_64-windows.zip -Algorithm SHA256
  Compare with the .sha256 file, extract, and run racomi.exe from a folder
  you can write. The EXE is not Authenticode-signed.

Updates: stable builds check signed updates in Settings > About, then replace
racomi.exe and restart.

Uninstall: exit racomi and delete the files. Data in %APPDATA%\racomi and
deployed skills are kept.

Symbolic link deployment needs Developer Mode or elevation; otherwise use copy
deployment. Building from source: see README.md (make install / make uninstall).
