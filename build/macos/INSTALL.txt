racomi for macOS / macOS 安装说明

Requires macOS 13 or newer on Apple Silicon. / 需要 Apple Silicon，macOS 13 或更新。

Install / 安装
  1. Verify the download / 校验下载：
       shasum -a 256 -c racomi-*-macos.zip.sha256
  2. Drag racomi.app into Applications (or ~/Applications).
     将 racomi.app 拖入“应用程序”（或 ~/Applications）。
  Git is needed for Git sources. / 导入 Git 来源需要本机 Git。

First launch / 首次打开
  The app is ad-hoc signed and not notarized. If macOS blocks it, open it once,
  then choose System Settings > Privacy & Security > Open Anyway. If it is still
  blocked, run:
  应用未经公证。若被拦截，先尝试打开一次，再到“系统设置 > 隐私与安全性”
  选择“仍要打开”；仍受阻时执行：
       xattr -dr com.apple.quarantine /Applications/racomi.app

Updates / 更新
  Stable builds check signed updates in Settings > About.
  正式版在“设置 > 关于”检查签名更新。

Uninstall / 卸载
  Quit racomi and move racomi.app to the Trash. Data in
  ~/Library/Application Support/racomi and deployed skills are kept.
  退出后将 racomi.app 移到废纸篓；数据与已部署技能会保留。
