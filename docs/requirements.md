# racomi 功能方案

状态：已确认，首版已实现<br>
日期：2026-10-12

racomi 是面向 Agent Skill 的轻量本地管理器，用于管理 Git 来源、下载和更新技能、按预设组织技能。应用到项目与应用到全局是两个独立功能：项目优先选用预设，按需直接选择技能；全局多选 Agent 的内置目录，再选择技能或预设。项目与全局的选择均自动保存，支持多目录应用，设置中可选择复制或软链接部署，本地技能更新后手动应用，全部技能选择按并集规则管理，备份采用本地快照和压缩包。用户已确认以下方案并授权实现。

## 已确认的需求

| 范围 | 需求 |
| --- | --- |
| 项目名称 | 使用 racomi。 |
| 功能参考 | 参考 [skills-manager](https://github.com/xingkongliang/skills-manager)，只保留所需能力，不追求完整复刻。 |
| 技能发现 | 采用 `skills.sh`；支持从 `skills.sh` 和 Git 下载技能并管理后续更新，也可从本地技能目录导入独立技能。 |
| 来源同步 | 独立保存 Git 来源及技能清单；支持默认挑选安装与显式整库订阅，刷新后手动同步本地技能。上游删除只标记并保留本地版本。 |
| 技能选择与预设 | 项目与全局均可直接选择技能，也支持预设；直接选择和多个预设的技能取并集。 |
| 备份 | 首版采用本地快照和压缩包导入导出；Git 或 GitHub 留作可选扩展。 |
| 项目 | 独立“项目”页，添加项目根目录与可选图标，优先选用预设，直接技能选择可折叠，展示当前启用技能；选择自动保存，预览后统一应用到多个目录。历史绝对路径保留。 |
| 全局 | 独立“全局”页，多选 Codex、Claude Code 或 Cursor 的内置技能目录及自定义绝对路径，保留旧版自定义全局配置。 |
| 技术方向 | 参考 [magpie](https://github.com/yetone/magpie) 的技术栈，按 Go、Wails、系统 WebView 和 TypeScript 前端初始化。 |
| 体验目标 | 保持轻量，避免管理操作卡顿。技术栈本身不构成性能保证。 |

## 首版功能边界

以下规则作为首版实现和验收依据。

### 来源、技能下载与更新

内容从远程 Git 仓库进入来源清单，再由用户安装或更新本地技能，最后直接选择技能或使用预设，手动应用到项目或全局目录。刷新来源、同步本地技能和应用部署目录是三个独立操作。

- 来源独立保存仓库地址、分支或引用、扫描子目录、订阅方式、最近刷新版本与时间、失败原因及技能清单。没有已安装技能时，来源仍可保存、刷新和浏览。
- Git 来源支持仓库地址，并可指定分支和子目录。仓库包含多个技能时，先列出候选，再由用户选择安装。扫描子目录限定来源的技能范围。
- “发现”页采用 `skills.sh`，默认按官网 All Time 榜单顺序浏览，每页 200 条并支持加载更多；搜索词留空返回未过滤的榜单，也可输入关键词搜索并预览下载。
- 发现列表展示后，按 Git 仓库合并后台核验技能可用性并短期缓存结果。确认上游已移除或改名的条目直接标记并提供“查看仓库当前技能”，由用户重新选择后导入；网络、权限或读取失败只显示“未能核验”，保持可预览。核验不得阻塞搜索与前台预览，也不改变榜单顺序或当前列表焦点、滚动位置。
- “发现”页可选择或填写本地技能目录，支持单个含 `SKILL.md` 的目录与包含多个技能的父目录；预览并勾选后导入为独立技能，无需 Git 仓库。
- 首版导入其 Git 来源；域名 / well-known 来源显示暂不支持，不影响其他搜索结果。
- 已安装的技能关联来源，并保存来源、分支或引用、子目录及当前版本信息，方便检查更新和恢复。
- Git 仓库与 skills.sh 使用同一分发副本规则：同仓库、同 Git 引用和同目录范围内，`skills`、`.agents/skills`、`.claude/skills` 等标准分发目录中的同名技能按一个技能展示和计数。整个技能目录的内容相同只保留一个选项；内容不同则保留可选变体，每次只安装一个。默认优先 `skills`、`.agents/skills`、`.claude/skills`；实际来源路径始终保留，用于检查更新。同一分发目录内存在多个同名路径时保留歧义，不任意合并；不同仓库和独立目录范围也不合并。
- 来源刷新与整库订阅默认保留已安装的变体，用户可明确选择其他变体再同步；切换保留技能 ID、安装时间、预设及项目引用。历史重复记录在该技能下次导入或同步时归并引用，操作前保留本地快照；刷新本身不替换本地技能内容。
- 刷新从仓库获取最新内容并重建清单，展示新增、可更新和上游移除；保留移除条目的状态供查看。刷新只更新清单与状态，不替换本地技能内容。
- 刷新在后台进行；来自同一 Git 仓库的技能共用一次仓库检查，避免重复请求。仓库访问或扫描失败时保留上次有效清单与本地版本，不误报为上游删除。
- 刷新不跟随仓库符号链接。与技能无关的符号链接静默跳过；符号链接阻断所选扫描目录时显示提示，其他不支持的特殊文件仍显示提示。技能目录内含不支持内容、元数据无效或无法读取时，仅将该技能标记“本次跳过”并展示原因，保留上次有效清单条目与本地版本，其他有效技能继续刷新与同步。首次发现的无效技能也列出路径与原因；被跳过技能不计入新增、更新或上游移除，不能选择、全选、重新关联或同步，待上游修复后重新刷新恢复。
- 同步前展示受影响的技能和变化摘要，用户确认后更新本地技能；保留旧版本以便恢复。两种订阅方式都需要手动同步。
- 本地技能更新后将相关项目和全局配置标记为“待应用”，由用户决定何时刷新部署目录。

| 来源方式或变化 | 行为 |
| --- | --- |
| 挑选安装（默认） | 新发现的技能只在清单中提示，由用户选择安装；已安装技能可选择更新。 |
| 整库订阅（显式开启） | 扫描范围内的所有技能及后续新增技能自动进入同步计划，手动同步时安装或更新。 |
| 首次全选导入 | 只表示安装当时选中的技能，不自动开启整库订阅。 |
| 上游删除技能 | 标记“来源已移除”，保留本地内容、技能身份和预设引用，不自动删除。 |
| 上游移动路径或改名 | 用户选择新的清单条目重新关联，保留原技能身份和预设引用，随后同步内容。 |
| 删除来源 | 删除来源配置及清单并解除技能的关联，保留本地技能和预设，不修改部署目录。 |

旧版索引、快照和 ZIP 恢复时按仓库地址与 Git 引用归并为来源，默认采用“挑选安装”，保留现有技能及预设关系。用户之后可刷新完整清单，并显式切换为整库订阅。

### 项目、全局与预设

“项目”与“全局”是两个独立页面和使用流程。

- 项目：添加项目根目录与名称，可选择项目图标，未设置时使用默认项目图标。可勾选预设或来源，零散技能可展开“直接选择技能”补充；勾选内置技能目录或设置中保存的目录模板，选择自动保存后预览并应用。
- 项目批量应用：列表复选框与右侧详情独立，多选后统一预览和应用，保留每个项目各自的技能与目录配置；搜索和筛选隐藏的勾选项仍参与批量操作。全部项目先校验，冲突不会导致部分应用。
- 项目排序：支持拖动把手和上、下方向键调整手动顺序并在本机持久化；可切换名称升降序、最近更新或最近添加，切换排序不覆盖手动顺序。项目时间记录配置变化，应用文件不改变配置时间；旧项目按原索引文件时间一次性补齐。
- 目录文案：项目与全局的内置目录仅显示 Agent 名称与路径，去掉“共享技能目录”“兼容技能目录”“用户技能目录”等附加说明。
- 全局：顶部使用紧凑的目录多选区，下方单栏复用项目级技能配置。同时选择一个或多个 Agent 的内置技能目录或设置中保存的自定义绝对路径，直接选择技能、勾选预设或来源，选择自动保存后预览并应用；Agent 内置路径无需手动填写，并提示可到设置中添加全局目录。
- 预设是可命名、可编辑的技能集合，同一个预设可以供多个项目及全局配置使用。每个项目和全局配置分别记录直接选择的技能、启用的预设和来源，以及部署记录。

采用以下操作规则：

| 操作 | 行为 |
| --- | --- |
| 直接选择技能 | 将其纳入该项目或全局配置的应用结果。 |
| 启用一个或多个预设 | 与直接选择的技能取并集，同一技能只保留一份。 |
| 启用一个或多个来源 | 与其他选择取并集，纳入该来源在本地技能库中已安装的全部技能（含保留的上游移除版本）。新增安装或云同步新增的技能进入下一次手动应用范围；未安装的清单条目需先从来源同步。 |
| 取消直接选择、停用预设或来源 | 重新计算并集；只移除不再被任何选择需要且由 racomi 管理的技能。 |
| 修改技能、预设或来源选择 | 自动保存配置，不再提供“保存选择”按钮，不创建目录或写入技能文件。 |
| 预览并应用 | 展示新增、更新、移除及冲突，用户明确应用后修改部署目录。 |
| 修改预设成员 | 提示受影响项目和全局配置待应用，用户重新应用后生效。 |
| 本地技能更新 | 提示受影响项目和全局配置待应用，用户重新应用后刷新。 |
| 部署目录中出现同名内容或手动修改 | 普通应用停止并保留现有内容；展示完整覆盖／删除路径，支持用户明确确认后强制覆盖。重复技能部署名、损坏内容和无效目录仍阻断。 |

界面展示“当前启用的技能”，即直接选择、所有已启用预设与来源已安装技能的并集，同一技能只展示一份；待应用时，这份配置尚未完全同步到部署目录。修改选择、编辑预设或更新本地技能不会立即改写部署目录。自动保存失败须明确提示，预览与应用须使用最新且成功保存的选择。重新应用时按当前直接选择的技能和启用的预设、来源重新计算结果；取消一项选择后，其他选择仍需要的技能保留。删除来源会解除相应的项目与全局来源选择，保留已安装技能、预设与部署记录；预览并应用后才移除不再需要的部署。

部署方式可在设置中选择复制（默认）或软链接。软链接指向本地技能的固定内容版本，更新本地技能后仍需手动应用。改变部署方式会标记待应用；预览并应用后转换所有选中目录。目录与部署记录按路径分别管理，普通应用遇到一处冲突会取消整批操作。强制覆盖支持整批目录，确认后内容变化须重新预览；发生普通 I/O 或保存失败时回滚全部已修改目录。

### 路径与管理范围

全局提供共享目录与各 Agent 的内置目录，项目单独选择根目录：

| 功能与 Agent | 部署路径 | 规则 |
| --- | --- | --- |
| 全局 · 共享 | `$HOME/.agents/skills` | Codex 与 Cursor 共用的本机用户技能目录，是新配置的默认选择。 |
| 全局 · Codex 兼容目录 | `$CODEX_HOME/skills`，默认 `~/.codex/skills` | 保留已有配置；使用启动应用时的 CODEX_HOME，不改变共享目录。新配置建议使用 `~/.agents/skills`。 |
| 全局 · Claude Code | `$HOME/.claude/skills` | Claude Code 本机用户技能目录；Cursor 也可兼容读取。 |
| 全局 · Cursor | `$HOME/.cursor/skills` | Cursor 本机用户技能目录。 |
| 项目 · 共享 | `<所选项目根目录>/.agents/skills` | Codex 与 Cursor 共用的项目技能目录。 |
| 项目 · Claude Code | `<所选项目根目录>/.claude/skills` | Claude Code 项目技能目录；Cursor 也可兼容读取。 |
| 项目 · Codex 兼容目录 | `<所选项目根目录>/.codex/skills` | 保留已有配置；新项目建议使用 `.agents/skills`。Cursor 可兼容读取此路径。 |
| 项目 · Cursor | `<所选项目根目录>/.cursor/skills` | Cursor 项目技能目录。 |
| 自定义项目目录模板 | 相对项目根目录的路径（可包含 `../`） | 在设置中管理，可与内置目录多选；历史绝对路径保持原位置。 |
| 自定义全局配置 | 用户选择或填写的绝对路径 | 在设置中新增、编辑和删除，与 Agent 内置目录同时选择；旧版自定义配置继续保留。 |

用户目录根据 HOME 解析，不随 CODEX_HOME 改变。浏览 Agent 内置目录和添加项目仅提供路径或保存配置，不创建部署目录、不扫描用户全盘，也不自动迁移已有技能；部署须预览后手动应用。路径规则依据 [Codex 官方目录说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)、[CODEX_HOME 环境变量说明](https://learn.chatgpt.com/docs/config-file/environment-variables#core-locations)、[Claude Code 技能说明](https://code.claude.com/docs/en/skills) 和 [Cursor 技能说明](https://cursor.com/docs/skills)。

目录标签说明主要用途，不保证技能隔离：`.agents/skills` 为 Codex 与 Cursor 的共享路径，Cursor 还兼容读取默认 `.claude/skills` 与 `.codex/skills` 用户和项目路径。项目配置只管理该项目的部署目录；若 Agent 同时加载全局技能，在项目中取消选择或停用预设不会停用全局技能。为兼容已有默认设置，内部 `codex-user` 和 `codex-project` 标识继续保留，显示名称更新不会改动用户路径、选择或部署记录。

普通应用只移除自己管理且未被手动修改的部署内容。对同名未托管内容、大小写名称冲突、被替换的软链接和本地修改，先展示冲突及完整受影响路径，用户明确确认后可强制覆盖或删除。强制覆盖不提供旧文件恢复，须在确认界面提醒自行备份；与技能无关的目录内容继续保留。

项目目录模板在设置中新增、编辑和删除，保存名称与相对项目根目录的路径；新增模板或修改路径不接受绝对路径、`~/` 或盘符路径。同 ID 的历史绝对路径模板可保留原路径或改名，已有项目的绝对 `customPaths` 也继续读取和使用。默认项目目录可混合内置目录 ID 与模板 ID。项目选择模板后保存独立的 `customPaths` 路径快照，编辑或删除模板不修改已有项目配置或部署；历史路径仍在项目选择器中保留，用户可自行退选并在下一次应用时清理受管理技能。删除模板会清理默认引用，若默认项目目录为空则回退到共享技能目录。

自定义全局目录也在设置中管理，可作为默认选择；若删除后没有默认全局目录，回退到共享用户目录。编辑已有部署的全局目录路径或删除配置前，先清空技能与预设选择，等待自动保存后预览并应用以移除已部署内容。内置全局目录不能编辑或删除。

### 备份与恢复

本地快照和压缩包导入导出可独立使用；另在“设置 → 备份与迁移”提供可选 S3 / R2 加密双向同步与云端历史，不作为日常启停预设的前提。

- 更新、删除和恢复等会替换现有内容的操作前建立快照。
- 复用未变化的技能内容，避免每次备份重复复制全部本地技能。
- 本地快照不设数量或保留时间上限，暂不自动清理；单份 JSON 清单最多 32 MiB，历史技能内容保留于对象存储。
- 导出包含技能文件、来源配置与技能清单、订阅方式、上游移除状态和预设；未安装任何技能的来源也包含在内。本机项目和全局路径单独记录，导入时不直接应用旧的绝对路径。
- 恢复先还原本地技能、来源和预设，再由用户重新配置项目和全局的技能选择。
- 恢复保留本机项目、全局配置与部署记录，清空直接选择的技能和已启用预设、来源，重新选择并手动应用；恢复本身不修改部署目录，压缩包不携带本机项目、全局路径和历史快照。
- ZIP 沿用 `racomi-backup` 格式 version 1，支持旧索引 schema 1 和来源索引 schema 2，旧版恢复时自动迁移；导出不携带 Git 缓存。ZIP 最大 128 MiB，清单最大 16 MiB，展开技能文件最大 512 MiB / 10,000 条目。

本地备份解决本机误操作与版本回退。多台电脑也可连接自己的私有 S3 / R2 存储，按共同基线双向合并来源、技能文件、预设及可移植设置。独立记录的变化自动合并，删除传播，同一记录的双边修改或修改与删除冲突须逐条选择。自动同步默认关闭，开启后仅在应用打开时按间隔运行。共享设置包含主题、语言、导航布局、部署方式、内置目录默认选择与相对项目目录模板；项目根目录、自定义绝对路径、项目／全局选择和部署记录保留本机，云端变化仍需手动应用。

共享清单、内容对象及不可变历史采用客户端加密。凭据和口令只存本机，优先存入系统凭据存储（手动 S3 在凭据存储不可用时回退为 `0600` 私有配置文件），界面不回显已保存敏感值，也不进入 ZIP。云端历史列表显示最近 100 个已提交版本，恢复先创建本地快照，再发布为新的同步版本。连接测试验证对象权限与条件写入，安全提交依赖 ETag 和 If-Match / If-None-Match。配置详见 [S3 / R2 配置指南](s3-r2-sync.md)。

## 界面与主题

界面布局、控件密度、主题和配色参考 [magpie main 的 74b30cb 版本](https://github.com/yetone/magpie/commit/74b30cb)，使用可切换的侧边栏／顶部导航和紧凑列表。导航布局默认自动：窗口宽度达到 1024px 时使用侧边栏，较窄时使用顶部导航；设置可固定使用任一布局。侧边栏按“技能管理”（发现、来源、技能、预设）和“应用部署”（全局、项目）分组，指南与设置位于底部。顶部按钮可切换侧边栏显示，macOS 支持 Control + Command + S，其他平台支持 Ctrl + Shift + S；侧边栏可收起，边缘支持拖拽及键盘调整宽度，并可重置宽度。布局偏好、侧边栏宽度与收起状态保存在本机，切换不丢失当前页面、搜索、选择和滚动位置。支持明亮、深色及跟随系统，保存本机外观偏好并在启动首帧应用。“技能”页提供名称、描述、来源搜索，按名称排序和更新 / 待应用筛选；技能详情可只读查看 SKILL.md，默认呈现 Markdown 排版，支持“原文”开关查看完整文本；概览与文档各自在内容容器内滚动，详情标题、标签、原文开关和底部操作保持可见；YAML 元信息默认折叠，章节链接可在文档内跳转；相对附件引用显示其原始路径。文档只读取本地文件，不等待来源网络请求或遍历无关附件；读取失败显示原因并支持重试，内容版本变化时重新加载。独立“来源”页提供新增、编辑、刷新、浏览清单、查看变化、挑选安装或整库订阅、同步与删除；展示新增、可更新和上游移除状态；“同步技能到本地”操作位于“全部技能”筛选所在行右侧。各页支持快捷搜索。

技能、来源、预设、项目及发现页预览的双栏工作区支持拖动分隔线调整宽度，也可用方向键调整、双击恢复默认比例；各页比例保存在本机。窄屏上下排列时隐藏分隔线。

“项目”页提供紧凑项目列表、可选项目图标与单项目详情，优先展示预设，直接技能选择可折叠，当前启用技能始终可见，技能标签不展示图标；“全局”页采用单栏，顶部紧凑选择目录，下方复用项目级技能配置。两页只勾选已有的内置／自定义目录，目录的新增、编辑和删除集中于设置。两页的技能、预设与来源选择均自动保存，保留预览和应用操作，展示应用结果与待应用状态。预设与来源各有独立搜索框，分别匹配预设名称／描述、来源名称／仓库地址；搜索按项目或当前全局目录组合分别保留，不修改已选配置，被过滤隐藏的选中项仍保留。

“设置”集中管理外观、导航布局、语言、部署方式、项目目录模板、自定义全局目录及两者的默认选择，以及备份、恢复和 skills-manager 迁移；目录管理采用紧凑分组行与图标操作，内置目录只读，自定义目录可新增、编辑和删除。设置逐项自动保存，外观、导航布局与语言即时生效，部署方式更改后仍需手动应用到项目或全局。界面支持简体中文、繁體中文和 English，默认跟随系统语言；字典与占位符方式参考 magpie。技能名称、说明与 SKILL.md 保留原文。

Agent 图标使用本地打包的 Magpie／Lobe Icons SVG，包含 Claude Code、Codex 与 Cursor，单色图标跟随主题；分发时保留对应 MIT 许可与来源说明。

结果和错误参考 magpie 使用单条紧凑状态提示，长内容单行省略并在悬停时显示完整文案；错误文字可选中，弹窗打开时提示浮于遮罩之上，避免挤动页面内容。

“技能”页与预设编辑共用搜索、来源、更新／待应用与排序筛选；明确区分有来源与本地无来源技能，详情可反查来源，筛选变化不丢失已选技能。

技能管理继续遵循本文的复制／软链接部署、直接选择与预设并集和手动应用规则。

## 轻量原则

应用启动优先读取本地索引和已知状态，界面可用后再执行网络检查。下载、检查更新和备份应展示进度、结果及失败原因，避免阻塞预设、项目和全局配置的操作。

磁盘扫描围绕用户选择的来源和部署目录进行，不在启动时遍历全部仓库。只有用户刷新、下载、同步、明确执行备份或开启自动云同步时才访问相应网络服务。云同步关闭时完全使用本地资料。

## 首版非目标

- 支持全局内置目录之外的 Agent 安装适配器。
- 托管、发布或评审技能，执行技能中的脚本。
- racomi 用户账号、团队权限与官方托管云端服务；双向同步使用用户自备的 S3 / R2 存储。
- 自动向 GitHub 推送备份，或持续修改所有已应用项目和全局目录。
- 复刻 skills-manager 的全部功能。

## 验收方向

1. 从 `skills.sh` 或 Git 安装技能后，能看到其来源、版本和更新状态；更新失败时仍保留可用的旧内容。
2. 保存未安装技能的来源后仍可刷新；挑选安装只提示新增，整库订阅将新增纳入手动同步计划，上游删除和刷新失败均保留本地内容。
3. 项目与全局为独立页面，只勾选目录并应用技能、预设或来源；项目目录模板与自定义全局目录的新增、编辑、删除统一在设置中管理。
4. 直接选择、多个预设与来源已安装技能取并集；取消一项技能、预设或来源选择后仍被其他选择需要的技能保留。保存配置不部署，预览并手动应用后生效。
5. 更新本地技能或修改预设后提示待应用；遇到手动修改或同名内容时整次取消，不静默覆盖。
6. 多个项目子目录与多个全局目录可统一预览和应用；一处冲突取消普通整批应用，可预览并确认强制覆盖；阻断冲突不能强制跳过。移除目录在下一次应用时清理其受管理技能。复制／软链接切换保留冲突检查和手动应用规则。
7. 设置和语言选择可持久化，默认项目与全局目录均可包含自定义项；模板编辑／删除保留已有项目路径快照。三种界面语言覆盖主要页面、弹窗和紧凑状态提示，用户内容不翻译。技能与预设均可按来源筛选并保留选择，可双向查看技能与来源。
8. 可导出并恢复技能、来源清单与订阅方式及预设，兼容旧版索引、快照和 ZIP；恢复保留本机项目、全局路径和部署记录，清空直接选择、预设与来源，部署目录保持手动应用。
9. S3 / R2 冲突在所有页面持续提示，可逐项选择或一键选择全部本地／云端版本，明确提交后生效，失败保留选择。支持首次双向合并、增删改传播、冲突选择、断网重试、加密技能对象及历史恢复；凭据与绝对路径不共享，自动同步可选且仅在应用打开期间运行。
