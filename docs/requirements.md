# racomi 功能方案

状态：已确认，首版已实现<br>
日期：2026-10-12

racomi 是面向 Agent Skill 的轻量本地管理器，用于管理 Git 来源、下载和更新技能、按预设组织技能。应用到项目与应用到全局是两个独立功能：项目直接选择技能，也支持预设；全局多选 Agent 的内置目录，再选择技能或预设。项目与全局均支持多目录应用，设置中可选择复制或软链接部署，本地技能更新后手动应用，全部技能选择按并集规则管理，备份采用本地快照和压缩包。用户已确认以下方案并授权实现。

## 已确认的需求

| 范围 | 需求 |
| --- | --- |
| 项目名称 | 使用 racomi。 |
| 功能参考 | 参考 [skills-manager](https://github.com/xingkongliang/skills-manager)，只保留所需能力，不追求完整复刻。 |
| 技能发现 | 采用 `skills.sh`；支持从 `skills.sh` 和 Git 下载技能，并管理后续更新。 |
| 来源同步 | 独立保存 Git 来源及技能清单；支持默认挑选安装与显式整库订阅，刷新后手动同步本地技能。上游删除只标记并保留本地版本。 |
| 技能选择与预设 | 项目与全局均可直接选择技能，也支持预设；直接选择和多个预设的技能取并集。 |
| 备份 | 首版采用本地快照和压缩包导入导出；Git 或 GitHub 留作可选扩展。 |
| 项目 | 独立“项目”页，添加项目根目录，选择技能或预设，多选 Agent 内置目录及自定义相对路径模板，历史绝对路径保留，预览并统一应用。 |
| 全局 | 独立“全局”页，多选 Codex、Claude Code 或 Cursor 的内置技能目录及自定义绝对路径，保留旧版自定义全局配置。 |
| 技术方向 | 参考 [magpie](https://github.com/yetone/magpie) 的技术栈，按 Go、Wails、系统 WebView 和 TypeScript 前端初始化。 |

## 首版功能边界

以下规则作为首版实现和验收依据。

### 来源、技能下载与更新

内容从远程 Git 仓库进入来源清单，再由用户安装或更新本地技能，最后直接选择技能或使用预设，手动应用到项目或全局目录。刷新来源、同步本地技能和应用部署目录是三个独立操作。

- 来源独立保存仓库地址、分支或引用、扫描子目录、订阅方式、最近刷新版本与时间、失败原因及技能清单。没有已安装技能时，来源仍可保存、刷新和浏览。
- Git 来源支持仓库地址，并可指定分支和子目录。仓库包含多个技能时，先列出候选，再由用户选择安装。扫描子目录限定来源的技能范围。
- “发现”页采用 `skills.sh`，作为搜索和下载技能的来源入口。
- 首版导入其 Git 来源；域名 / well-known 来源显示暂不支持，不影响其他搜索结果。
- 已安装的技能关联来源，并保存来源、分支或引用、子目录及当前版本信息，方便检查更新和恢复。
- 刷新从仓库获取最新内容并重建清单，展示新增、可更新和上游移除；保留移除条目的状态供查看。刷新只更新清单与状态，不替换本地技能内容。
- 刷新在后台进行；来自同一 Git 仓库的技能共用一次仓库检查，避免重复请求。仓库访问或扫描失败时保留上次有效清单与本地版本，不误报为上游删除。
- 刷新不跟随仓库符号链接。与技能无关的符号链接或特殊文件跳过并显示提示；技能目录内含不支持内容、元数据无效或无法读取时，仅将该技能标记“本次跳过”并展示原因，保留上次有效清单条目与本地版本，其他有效技能继续刷新与同步。首次发现的无效技能也列出路径与原因；被跳过技能不计入新增、更新或上游移除，不能选择、全选、重新关联或同步，待上游修复后重新刷新恢复。
- 同步前展示受影响的技能和变化摘要，用户确认后更新本地技能；保留旧版本以便恢复。两种订阅方式都需要手动同步。
- 本地技能更新后将相关项目和全局配置标记为“待应用”，由用户决定何时刷新部署目录。

| 来源方式或变化 | 行为 |
| --- | --- |
| 挑选安装（默认） | 新发现的技能只在清单中提示，由用户选择安装；已安装技能可选择更新。 |
| 整库订阅（显式开启） | 扫描范围内的所有技能及后续新增技能自动进入同步计划，手动同步时安装或更新。 |
| 首次全选导入 | 只表示安装当时选中的技能，不自动开启整库订阅。 |
| 上游删除技能 | 标记“来源已移除”，保留本地内容、技能身份和预设引用，不自动删除。 |
| 上游移动路径或改名 | 用户选择新的清单条目重新关联，保留原技能身份和预设引用，随后同步内容。 |
| 删除来源 | 删除来源配置及清单并解除技能的关联，保留本地技能和预设，不修改部署目录。 |

旧版索引、快照和 ZIP 恢复时按仓库地址与 Git 引用归并为来源，默认采用“挑选安装”，保留现有技能及预设关系。用户之后可刷新完整清单，并显式切换为整库订阅。

### 项目、全局与预设

“项目”与“全局”是两个独立页面和使用流程。

- 项目：添加项目根目录与名称，勾选内置技能目录或设置中保存的目录模板，在项目中直接选择技能，也可勾选预设，保存后预览并应用。
- 全局：同时选择一个或多个 Agent 的内置技能目录或设置中保存的自定义绝对路径，直接选择技能或勾选预设，保存后预览并应用；Agent 内置路径无需手动填写。
- 预设是可命名、可编辑的技能集合，同一个预设可以供多个项目及全局配置使用。每个项目和全局配置分别记录直接选择的技能、启用的预设与部署记录。

采用以下操作规则：

| 操作 | 行为 |
| --- | --- |
| 直接选择技能 | 将其纳入该项目或全局配置的应用结果。 |
| 启用一个或多个预设 | 与直接选择的技能取并集，同一技能只保留一份。 |
| 取消直接选择或停用预设 | 重新计算并集；只移除不再被任何选择需要且由 racomi 管理的技能。 |
| 保存选择 | 仅保存配置，不创建目录或写入技能文件。 |
| 预览并应用 | 展示新增、更新、移除及冲突，用户明确应用后修改部署目录。 |
| 修改预设成员 | 提示受影响项目和全局配置待应用，用户重新应用后生效。 |
| 本地技能更新 | 提示受影响项目和全局配置待应用，用户重新应用后刷新。 |
| 部署目录中出现同名内容或手动修改 | 显示冲突并取消整次应用，保留现有内容，用户处理后再应用。 |

修改选择、编辑预设或更新本地技能不会立即改写部署目录。重新应用时按当前直接选择的技能和启用的预设重新计算结果；停用一个预设后，直接选择或其他预设仍需要的技能保留。

部署方式可在设置中选择复制（默认）或软链接。软链接指向本地技能的固定内容版本，更新本地技能后仍需手动应用。改变部署方式会标记待应用；预览并应用后转换所有选中目录。目录与部署记录按路径分别管理，一处冲突会取消整批应用，发生普通 I/O 或保存失败时回滚全部已修改目录。

### 路径与管理范围

全局按 Agent 提供内置目录，项目单独选择根目录：

| 功能与 Agent | 部署路径 | 规则 |
| --- | --- | --- |
| 全局 · Codex | `$HOME/.agents/skills` | 用户技能目录，作为 Codex 的默认选择。 |
| 全局 · Codex 兼容目录 | `$CODEX_HOME/skills`，默认 `~/.codex/skills` | 使用启动应用时的 CODEX_HOME，直接作为技能目录，不追加项目后缀。 |
| 全局 · Claude Code | `$HOME/.claude/skills` | Claude Code 用户技能目录。 |
| 全局 · Cursor | `$HOME/.cursor/skills` | Cursor 用户技能目录。 |
| 项目 | `<所选项目根目录>/.agents/skills`、`.claude/skills`、`.codex/skills`、`.cursor/skills`，以及设置中保存的自定义目录模板（多选） | 必须由用户选择项目根目录；新增或修改模板路径须为相对路径（含 `../`），从该根目录解析；历史绝对路径保持原位置。 |
| 自定义全局配置 | 用户选择或填写的绝对路径 | 在设置中新增、编辑和删除，与 Agent 内置目录同时选择；旧版自定义配置继续保留。 |

用户目录根据 HOME 解析，不随 CODEX_HOME 改变。浏览 Agent 内置目录和添加项目仅提供路径或保存配置，不创建部署目录、不扫描用户全盘，也不自动迁移已有技能；部署须预览后手动应用。路径规则依据 [Codex 官方目录说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)、[CODEX_HOME 环境变量说明](https://learn.chatgpt.com/docs/config-file/environment-variables#core-locations)、[Claude Code 技能说明](https://code.claude.com/docs/en/skills) 和 [Cursor 技能说明](https://cursor.com/docs/skills)。

Agent 选择用于确定部署目录，不保证技能隔离：Codex 的 `~/.agents/skills` 也是 Cursor 可读取的共享路径。项目配置只管理该项目的部署目录；若 Agent 同时加载全局技能，在项目中取消选择或停用预设不会停用全局技能。

racomi 只移除自己管理的部署内容。对已有的其他技能、同名目录和手动修改，先展示状态或冲突，再决定如何处理。

项目目录模板在设置中新增、编辑和删除，保存名称与相对项目根目录的路径；新增模板或修改路径不接受绝对路径、`~/` 或盘符路径。同 ID 的历史绝对路径模板可保留原路径或改名，已有项目的绝对 `customPaths` 也继续读取和使用。默认项目目录可混合内置目录 ID 与模板 ID。项目选择模板后保存独立的 `customPaths` 路径快照，编辑或删除模板不修改已有项目配置或部署；历史路径仍在项目选择器中保留，用户可自行退选并在下一次应用时清理受管理技能。删除模板会清理默认引用，若默认项目目录为空则回退到 Agents。

自定义全局目录也在设置中管理，可作为默认选择；若删除后没有默认全局目录，回退到 Codex 用户目录。编辑已有部署的全局目录路径或删除配置前，先清空技能与预设选择，保存并应用以移除已部署内容。内置全局目录不能编辑或删除。

### 备份与恢复

首版采用本地快照和压缩包导入导出。Git 或 GitHub 作为后续可选备份方式，不作为日常启停预设的前提。

- 更新、删除和恢复等会替换现有内容的操作前建立快照。
- 复用未变化的技能内容，避免每次备份重复复制全部本地技能。
- 导出包含技能文件、来源配置与技能清单、订阅方式、上游移除状态和预设；未安装任何技能的来源也包含在内。本机项目和全局路径单独记录，导入时不直接应用旧的绝对路径。
- 恢复先还原本地技能、来源和预设，再由用户重新配置项目和全局的技能选择。
- 恢复保留本机项目、全局配置与部署记录，清空直接选择的技能和已启用预设，重新选择并手动应用；恢复本身不修改部署目录，压缩包不携带本机项目、全局路径和历史快照。
- ZIP 沿用 `racomi-backup` 格式 version 1，支持旧索引 schema 1 和来源索引 schema 2，旧版恢复时自动迁移；导出不携带 Git 缓存。ZIP 最大 128 MiB，清单最大 16 MiB，展开技能文件最大 512 MiB / 10,000 条目。

该方案首先解决本机误操作和版本回退。多台电脑可手动导入导出压缩包；自动双向同步不纳入首版范围。

## 界面与主题

界面布局、控件密度、主题和配色参考 magpie，使用顶部标签和紧凑列表。支持明亮、深色及跟随系统，保存本机外观偏好并在启动首帧应用。“技能”页提供名称、描述、来源搜索，按名称排序和更新 / 待应用筛选；技能详情可只读查看 SKILL.md。独立“来源”页提供新增、编辑、刷新、浏览清单、查看变化、挑选安装或整库订阅、同步与删除；展示新增、可更新和上游移除状态。各页支持快捷搜索。

“项目”页提供项目列表、添加项目与项目技能选择；“全局”页提供 Agent 及内置目录选择和全局技能选择。两页只勾选已有的内置／自定义目录，目录的新增、编辑和删除集中于设置。两页均展示可直接勾选的技能、预设、应用结果与待应用状态，使用各自的保存、预览和应用操作。

“设置”集中管理外观、语言、部署方式、项目目录模板、自定义全局目录及两者的默认选择，以及备份、恢复和 skills-manager 迁移；目录管理采用紧凑分组行与图标操作，内置目录只读，自定义目录可新增、编辑和删除。设置逐项自动保存，外观与语言即时生效，部署方式更改后仍需手动应用到项目或全局。界面支持简体中文、繁體中文和 English，默认跟随系统语言；字典与占位符方式参考 magpie。技能名称、说明与 SKILL.md 保留原文。

Agent 图标使用本地打包的 Magpie／Lobe Icons SVG，包含 Claude Code、Codex 与 Cursor，单色图标跟随主题；分发时保留对应 MIT 许可与来源说明。

结果和错误参考 magpie 使用单条紧凑状态提示，长内容单行省略并在悬停时显示完整文案；错误文字可选中，弹窗打开时提示浮于遮罩之上，避免挤动页面内容。

“技能”页与预设编辑共用搜索、来源、更新／待应用与排序筛选；明确区分有来源与本地无来源技能，详情可反查来源，筛选变化不丢失已选技能。

技能管理继续遵循本文的复制／软链接部署、直接选择与预设并集和手动应用规则。

## 轻量原则

应用启动优先读取本地索引和已知状态，界面可用后再执行网络检查。下载、检查更新和备份应展示进度、结果及失败原因，避免阻塞预设、项目和全局配置的操作。

磁盘扫描围绕用户选择的来源和部署目录进行，不在启动时遍历全部仓库。只有用户刷新、下载、同步或明确执行备份时才访问相应网络服务。

## 首版非目标

- 支持全局内置目录之外的 Agent 安装适配器。
- 托管、发布或评审技能，执行技能中的脚本。
- 用户账号、团队权限、云端服务和自动双向同步。
- 自动向 GitHub 推送备份，或持续修改所有已应用项目和全局目录。
- 复刻 skills-manager 的全部功能。

## 验收方向

1. 从 `skills.sh` 或 Git 安装技能后，能看到其来源、版本和更新状态；更新失败时仍保留可用的旧内容。
2. 保存未安装技能的来源后仍可刷新；挑选安装只提示新增，整库订阅将新增纳入手动同步计划，上游删除和刷新失败均保留本地内容。
3. 项目与全局为独立页面，只勾选目录并应用技能或预设；项目目录模板与自定义全局目录的新增、编辑、删除统一在设置中管理。
4. 直接选择与多个预设取并集；取消一项技能或预设选择后仍被其他选择需要的技能保留。保存配置不部署，预览并手动应用后生效。
5. 更新本地技能或修改预设后提示待应用；遇到手动修改或同名内容时整次取消，不静默覆盖。
6. 多个项目子目录与多个全局目录可统一预览和应用；一处冲突取消整批操作，移除目录在下一次应用时清理其受管理技能。复制／软链接切换保留冲突检查和手动应用规则。
7. 设置和语言选择可持久化，默认项目与全局目录均可包含自定义项；模板编辑／删除保留已有项目路径快照。三种界面语言覆盖主要页面、弹窗和紧凑状态提示，用户内容不翻译。技能与预设均可按来源筛选并保留选择，可双向查看技能与来源。
8. 可导出并恢复技能、来源清单与订阅方式及预设，兼容旧版索引、快照和 ZIP；恢复保留本机项目、全局路径和部署记录，清空直接选择与预设，部署目录保持手动应用。

## 已确认决策

| 决策 | 首版选择 |
| --- | --- |
| 发现来源 | skills.sh。 |
| 来源管理 | 来源独立于已安装技能；刷新清单、手动同步本地技能、手动应用项目或全局目录。 |
| 来源订阅 | 默认挑选安装；整库订阅须显式开启，将新增技能纳入同步计划。 |
| 上游删除 | 标记并保留本地版本与预设引用。 |
| 部署及传播技能更新 | 设置选择复制或软链接部署；本地技能更新后由用户手动应用到项目或全局目录。 |
| 项目与全局 | 两个独立应用页；设置集中管理项目目录模板与自定义全局目录，应用页多选目录并预览、应用。 |
| 技能选择与预设 | 直接选择与多个预设取并集；编辑成员后提示重新应用；仍被任一选择需要的技能保留。 |
