# racomi

轻量本地 Agent Skill 管理器。集中保存技能，在项目中直接选择技能或使用预设（Preset），也可选择 Agent 后应用到本机全局技能目录。首版功能依据 [已确认方案](docs/requirements.md) 实现。

## 当前功能

- 从 **skills.sh** 搜索技能，预览 Git 仓库并选择导入一个或多个技能。
- 独立管理 Git 来源，保存仓库、引用、扫描子目录和技能清单；尚未安装技能的来源也可保留。
- 来源默认“挑选安装”，也可设为“整库订阅”。刷新发现新增、更新和上游移除，再手动安装或更新本地技能。
- 记录来源、Git 引用、子目录和版本，查看变化摘要；上游删除仅标记并保留本地版本。
- 创建和编辑预设。项目与全局均支持直接选择技能、启用多个预设，最终应用全部选择的技能并集，共享技能只保留一份。
- 独立的“项目”页：添加项目根目录，在项目内选择技能和预设，多选 Agent 内置目录或设置中保存的自定义目录模板，预览后统一应用。
- 独立的“全局”页：多选 Codex、Claude Code、Cursor 的内置技能目录或设置中保存的自定义目录，统一选择技能与预设，并预览每个目录的变化。
- 保存选择、预览新增 / 更新 / 移除，再手动应用。本地技能或预设变化后提示“待应用”；浏览配置和保存选择均不会创建或部署技能目录。
- 同名未托管内容和本地修改会阻止整次应用，保留现有文件；只移除 racomi 管理且未被修改的技能。
- 自动与手动本地快照、ZIP 导出和恢复。恢复前自动备份当前状态。
- 在“设置 → 备份与恢复”预览并合并导入 skills-manager 的 SQLite 数据库、技能文件和场景组合；重复内容跳过，导入前自动快照。
- 设置集中管理外观、语言、复制／软链接部署，以及项目目录模板和自定义全局目录的新增、编辑、删除；项目和全局默认目录均可选择自定义项，备份与迁移也收纳于设置。
- “技能”页支持多选后的批量更新、批量移除；整批操作统一校验并创建一份快照，仍在预设或目标中使用的技能须先取消引用。
- “技能”页与预设编辑共用名称／描述／来源搜索、可输入来源名称或仓库地址过滤的来源下拉框、更新／待应用状态与名称排序。两处均支持对当前筛选结果全选、反选；切换筛选保留已选技能。
- 技能列表区分有来源的技能与“本地 · 无来源”技能；详情可反向打开来源及完整技能清单。

恢复还原本地技能、来源与预设，保留本机项目、全局配置和部署记录，清空直接选择的技能及预设；**不会直接修改部署目录**。恢复后重新选择技能或预设，预览并手动应用。ZIP 包含技能文件、来源配置与清单、订阅方式、上游移除标记及预设，不包含本机项目和全局路径、Git 缓存或历史快照。

## 使用

主导航依次为“发现 → 来源 → 技能 → 预设 → 全局 → 项目”；“设置”和“指南”位于右上角。“指南”包含工作流程、首次使用步骤与常见问题，不需要联网，也可在桌面服务未连接时阅读。

界面与项目文档统一使用以下名称：

| 中文 | English |
| --- | --- |
| 发现 | Discover |
| 来源 | Sources |
| 技能 | Skills |
| 预设 | Presets |
| 全局 | Global |
| 项目 | Projects |
| 设置 | Settings |
| 指南 | Guide |

1. 在“发现”搜索 skills.sh，或输入 Git 仓库地址。可指定分支、标签、Commit 和技能子目录；也可直接在“来源”保存仓库。
2. 在“来源”刷新技能清单。默认挑选需要的技能安装；整库订阅会把扫描范围内的所有技能及后续新增技能纳入同步计划。确认后同步所选技能，安装完成后可在“技能”查看，并在“预设”保存常用的技能集合。
3. 在“设置”管理项目目录模板和自定义全局目录，并选择默认目录。应用到项目时，打开“项目”，添加项目根目录，勾选内置目录或模板，再选择技能或预设，保存、预览并应用。
4. 应用到全局：打开“全局”，多选内置目录或设置中添加的自定义目录，直接选择技能或勾选预设，保存选择，预览后应用。
5. 后续刷新来源、查看变化并同步本地技能，再到对应项目或全局配置手动应用。备份可在“设置 → 备份与恢复”管理。

直接选择的技能与所选预设取并集。取消一个预设后，直接选择或其他预设仍需要的技能会保留；保存选择只保存配置，预览后的应用操作才修改目录。

刷新只更新来源清单和状态，不修改技能内容。挑选安装时，新技能等待选择；整库订阅时，新技能自动进入待同步计划，仍需手动同步。首次导入时全选技能不会自动开启整库订阅。与技能无关的仓库符号链接会跳过并显示提示；技能内容含符号链接、特殊文件或无效元数据时，该技能标记“本次跳过”并展示原因，保留上次有效清单与本地版本，不计入新增、更新或上游移除，也不能选择、重新关联或同步。其他有效技能可继续同步；修复上游后重新刷新即可恢复。仓库访问或整体扫描失败会显示错误并保留上次清单，不会把失败当成上游删除。

从 skills-manager 迁移：打开“设置”→“备份与恢复”→“导入 skills-manager”，选择 `~/.skills-manager/skills-manager.db`，预览数量与提示后点击“合并导入”。数据库旁须保留 `skills/` 文件夹；迁移其他机器的数据时请一起复制整个工作空间，若旧应用仍在运行，优先使用 SQLite 备份或同时保留 WAL 文件。应用使用内置 SQLite 驱动在一个只读事务中读取已提交的 WAL 数据，不需要安装 sqlite3 命令行工具，也不联网下载技能。

技能内容会重新校验并复制到 racomi；Git 来源成为“挑选安装”来源，场景成为预设，保留技能安装与更新时间。已存在且内容相同的技能保留 racomi 元数据；同名但成员不同的场景加上 ` (skills-manager)` 后缀。相同身份的不同内容会阻止整次导入，重复导入不会重复添加或生成空快照。预览 15 分钟内有效，技能内容变化后需重新预览。导入保留当前 racomi 数据、项目和全局配置，不会修改旧库或部署目录。旧项目、工具部署（包括软链接）、场景工具开关、当前场景、应用设置、标签、发现记录与操作历史暂不映射，预览会列出非空记录，请按需重新配置。

上游移除的技能保留本地内容与预设引用；路径移动后可重新关联到新的技能路径，保留原技能身份和预设引用。删除来源只解除来源关联，保留已安装技能。以上操作均不直接改写部署目录。旧版索引、快照和 ZIP 会按仓库及 Git 引用迁移为“挑选安装”来源，之后可刷新完整清单或改为整库订阅。

在“设置”切换外观与语言，默认跟随系统；语言支持简体中文、繁體中文与 English。设置逐项自动保存，外观与语言即时生效，部署方式更改后仍需手动应用到项目或全局。外观和语言偏好单独保存在本机 WebView 存储中，随重启保留。部署设置默认使用复制，可切换软链接；改变部署方式后，现有配置提示待应用，预览并应用后才转换已有技能。软链接指向本地技能的固定内容版本，本地技能更新后仍需手动应用。`⌘K`（其他系统为 `Ctrl+K`）聚焦当前页搜索，`Esc` 关闭弹窗。

多语言沿用 magpie 的字典、占位符插值与系统语言解析方式，界面参考 [magpie 的 GUI](https://github.com/yetone/magpie/tree/612b759d2141cccb4f477645c9d765c0878476b0/internal/gui/assets)：顶部居中标签、紧凑列表、灰阶界面与靛紫强调色，明暗配色贯穿列表、表单、弹窗和状态反馈。错误以紧凑状态提示显示，长文案省略并可悬停查看完整内容；弹窗中的错误浮于遮罩之上。macOS 使用融入内容的标题栏；系统文件选择器遵循 macOS 的外观设置。

Claude Code、Codex 和 Cursor 图标随应用本地打包，来自上述固定版本的 Magpie／Lobe Icons；彩色图标保留原色，Cursor 单色图标跟随主题。来源与 MIT 许可见 [第三方许可](frontend/public/THIRD_PARTY_NOTICES.txt)。

Git 来源支持 `owner/repo`、HTTPS / SSH 仓库地址、GitHub tree 地址、Git 来源的 skills.sh 详情链接，以及本地 Git 仓库绝对路径。程序只读取和复制技能，不执行其中的脚本。

全局内置目录如下，均根据本机环境解析：

| Agent | 全局技能目录 |
| --- | --- |
| Codex | `~/.agents/skills`，或兼容目录 `$CODEX_HOME/skills`（默认 `~/.codex/skills`） |
| Claude Code | `~/.claude/skills` |
| Cursor | `~/.cursor/skills` |

路径依据 [Codex](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)、[Claude Code](https://code.claude.com/docs/en/skills) 和 [Cursor](https://cursor.com/docs/skills) 的官方说明。Codex 用户目录始终根据本机 HOME 解析；兼容目录遵循启动 racomi 时的 `CODEX_HOME`，[未设置时使用 `~/.codex`](https://learn.chatgpt.com/docs/config-file/environment-variables#core-locations)。全局可同时选择 Agent 内置目录和自定义绝对路径，已有自定义配置保留。项目选择根目录后，可同时勾选 `.agents/skills`、`.claude/skills`、`.codex/skills`、`.cursor/skills` 或自定义目录模板：新增或修改模板路径须使用相对路径（含 `../`），从所选项目根目录解析；历史绝对路径继续保留。不会根据当前工作目录自动添加项目。

项目目录模板和自定义全局目录统一在“设置”中通过紧凑列表与图标操作管理。项目选择模板后保存路径快照；编辑或删除模板不会改变已有项目路径，历史路径仍可在项目中勾选。旧绝对路径模板可保留或改名，修改路径时须改为相对路径。项目默认目录可混合内置项与模板，删除模板后会清理默认引用；没有默认项目目录时回退到 Agents。

自定义全局目录可作为默认选择；若删除后没有默认全局目录，回退到 Codex 用户目录。编辑已有部署的全局目录路径或删除配置前，先清空技能与预设选择，保存并应用以移除已部署内容。

Agent 选择用于确定部署目录。Codex 的 `~/.agents/skills` 也是 Cursor 可读取的共享路径，因此目录选择不保证技能只供某一个 Agent 使用。在项目中取消技能也不会停用 Agent 从全局目录加载的技能。已有目录不会自动迁移；只有用户点击应用时才按设置复制所选技能或创建软链接。

macOS 默认数据目录为 `~/Library/Application Support/racomi`，可用 `RACOMI_DATA_DIR` 指定其他绝对路径。`state.json` 保存技能、来源清单与订阅方式等索引，`objects/` 保存按内容哈希去重的已安装技能版本，`snapshots/` 保存历史状态，`cache/sources/` 保存 Git 缓存。复制部署的副本独立存在；软链接部署依赖本地技能对象目录，不应直接编辑链接中的内容。

## 技术栈与环境

| 层级 | 选择 |
| --- | --- |
| 桌面应用 | Go + Wails v3.0.0-beta.24 + 系统 WebView |
| 前端 | 原生 TypeScript 5.9.3 + Vite 8.3.4 + CSS |
| 本地存储 | JSON 索引、内容寻址对象、本地快照与 ZIP；内置 SQLite 驱动读取旧库 |
| 依赖管理 | Go Modules、npm 与版本锁文件 |

技术方向参考 [magpie](https://github.com/yetone/magpie)，Wails 与前端 runtime 固定同一 beta.24。该版本仍是预发布版本，升级时需核对窗口与桥接 API。

开发需要 macOS 13+、Xcode Command Line Tools、Go 1.26.8+（CGO）、Node.js 22.12+、npm、make、Git。可用 `make GO=/opt/homebrew/bin/go` 指定 Go 路径。

```sh
make install
make check
```

在两个终端分别运行：

```sh
# 终端一：前端热更新
make frontend-dev

# 终端二：桌面应用
make dev
```

前端端口默认 `9245`，两个命令可同步附加 `VITE_PORT=其他端口`。管理功能需要 Wails 后端，直接访问 Vite 页面不能使用桌面服务。Go 代码修改后重新启动桌面应用。

浏览器界面验证可在启动前端开发服务器后访问 `http://127.0.0.1:9245/tests/browser.html`。该页面使用独立的内存工作空间，包含四个技能、两个来源与一个预设，支持筛选、全选／反选、批量更新／移除和预设保存，不访问本机技能、Wails 服务或部署目录；刷新页面即重置。点击“检查更新”可让两个有来源的技能显示可更新状态；批量移除可使用未被预设引用的两个本地技能。

```sh
make check    # TypeScript、前端构建、Go vet 与测试
make icons    # 从 AppIcon.icon 生成原生明暗图标、ICNS 和页面图标
make test     # 后端测试
make build    # bin/racomi，内嵌前端资源
make package  # bin/racomi.app，未签名的本机架构应用包
make run      # 构建并启动
```

生产构建使用 Wails 的 `production` 标签，不依赖开发服务器。macOS 最低部署版本统一为 `13.0`；可调整 `MACOSX_DEPLOYMENT_TARGET`，但需重新验证 Go 和系统 API 的兼容性。Go 嵌入 `frontend/dist`，直接执行 `go build` / `go vet` 前需先 `make frontend`。

图标原稿保存在 `build/design/racomi-mark.png`，原生图标文档为 `build/macos/AppIcon.icon`。参照 magpie，macOS 应用包使用 `Assets.car` 提供系统明暗 Dock 图标，运行时不会用普通 PNG 覆盖它。浅色采用白底黑浣熊，系统深色采用深灰底白浣熊；Dock 外观跟随 macOS 的图标外观设置，独立于应用内主题。

`make icons` 使用 Xcode 的 Icon Composer 与 actool，从同一图标文档导出明暗 1024px PNG、十种尺寸的 ICNS 和原生资源。兼容 PNG 保留四周 10% 的透明边距；应用包也包含标准“关于”面板使用的图标。资源已保存在仓库中，无完整 Xcode 时可复用；修改图标设计后需用完整 Xcode 重新生成。设计来源与生成提示见 [图标说明](build/design/README.md)。

测试覆盖多目录原子应用、复制／软链接切换、链接篡改保护、设置兼容迁移、来源筛选、语言字典一致性、来源刷新与同步、挑选安装和整库订阅、上游移除保留、直接选择与预设并集、手动更新应用、冲突时整次取消、恢复不改写部署目录、便携备份及旧版迁移。目录测试使用临时 HOME 和 CODEX_HOME，验证 Agent 全局路径、兼容目录不追加项目后缀、项目必须选择根目录，以及保存配置不创建部署目录。来源测试使用本地 Git 仓库；可选联网检查：

```sh
RACOMI_TEST_LIVE_SOURCES=1 go test ./internal/sources -run Live -v
```

## 首版限制

- skills.sh 中的 Git 来源可导入；域名 / well-known 来源会标明暂不支持。
- 目前面向 macOS，应用包未签名、未公证；没有跨平台安装器和自动升级。
- 技能原件仍不支持内部符号链接和特殊文件；仓库中与技能无关的链接会跳过，含不支持内容或无效元数据的技能单独跳过并显示原因，其他技能继续刷新与同步。已存在的技能保留上次有效版本；应用技能可按设置创建受管理的目录软链接，修改或替换链接会触发冲突保护。仓库预览最多 100 MiB / 20,000 条目；ZIP 最多 128 MiB，清单最多 16 MiB，展开内容最多 512 MiB / 10,000 条目。
- 自动快照与 Git 缓存暂不自动清理，历史较多时会增加磁盘占用。ZIP 导出只携带当前版本。
- 无云同步、GitHub 备份和账号；全局内置目录支持 Codex、Claude Code 和 Cursor，项目支持 `.agents`、`.claude`、`.codex`、`.cursor` 下的 `skills` 目录。使用 SSH 私有仓库时需预先配置本机 Git 认证，应用不会弹出交互登录。
